Privacy Policy - Hermes Agent

Last updated: October 12, 2026

Hermes Agent is a private automation tool operated by a single person, Chris Buuck, for the management of his own YouTube channel. It is not a public service and it has no users other than its owner.

What Google user data this application accesses

When authorized through Google Sign-In, Hermes Agent requests access to the following YouTube data belonging to the channel owner:

  • Basic channel information (channel name, channel ID, subscriber and video counts).
  • The list of the owner's own uploaded videos and their metadata.
  • Permission to upload new videos to the owner's own channel.
  • Permission to set video metadata, thumbnails and caption tracks on those videos.
  • YouTube Analytics data (views, watch time, audience retention) for the owner's own videos.

How the data is used

The data is used for exactly one purpose: publishing and maintaining the owner's own videos on the owner's own channel. Statistics are used to report performance back to the owner. The data is not used for advertising, profiling, marketing, or any purpose unrelated to managing the owner's own channel.

How the data is stored

Google user data is retrieved on demand and used in memory. Video files and their metadata are stored on the owner's own private equipment on his own home network. The only Google credential stored is an OAuth refresh token, held on the owner's own equipment with file permissions restricted to the owner's user account.

Sharing and disclosure

The data is not sold, rented, traded, transferred or disclosed to any third party. It is never shared with advertisers, data brokers, information resellers, credit agencies or any other party. No Google user data is used to train machine learning models. No humans other than the owner ever read the data.

Limited Use disclosure. Hermes Agent's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

Google user data is retained only while it is needed to operate the channel. The OAuth authorization can be revoked at any time, which immediately ends all access:

  • Revoke access: myaccount.google.com/permissions
  • Google account data controls: myaccount.google.com/data-and-privacy

Revoking access deletes the stored refresh token and stops all further access. To request deletion of any other data, or to ask any question about this policy, contact the address below.
