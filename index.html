Hermes Agent

Hermes Agent is a private, self-hosted automation tool that manages the owner's own YouTube channel. It runs on the owner's equipment and is used by exactly one person: the channel's owner. It has no other users and is not distributed.

What it does

  • Uploads finished video files to the owner's own YouTube channel.
  • Sets the title, description, tags and chapter timestamps on those videos.
  • Sets the video thumbnail.
  • Attaches caption (subtitle) tracks.
  • Schedules the public release of an already-uploaded video.
  • Reads back view, watch-time and retention statistics for the owner's own videos.

What it never does

  • It never touches any YouTube account other than the owner's own channel.
  • It never reads, modifies or deletes videos it did not upload.
  • It has no server, no sign-up, and no other users.
